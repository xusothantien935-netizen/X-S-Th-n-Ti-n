# HearPaw — website demo

Website tĩnh tiếng Việt cho HearPaw, được dựng bằng HTML, CSS và JavaScript thuần để dễ đưa lên GitHub và Render Static Site.

## Có gì trong demo?
- Trang chủ, sản phẩm, cá nhân hóa, My Pet và liên hệ.
- Chọn màu dây (6 màu), kích cỡ S/M/L và xem trước thiết kế.
- Giỏ hàng demo với giá 1.599.000đ và 1.748.000đ cho bản cá nhân hóa.
- My Pet dashboard: hồ sơ thú cưng, bản đồ minh họa có vùng an toàn, bán kính vùng an toàn, hoạt động, thông báo và cài đặt.
- Chatbot trả lời theo một số câu hỏi mẫu.
- Responsive cho máy tính và điện thoại.

## Chạy trên máy tính
Mở `index.html` trực tiếp trong trình duyệt. Hoặc dùng VS Code Live Server.

## Đưa lên GitHub và Render
1. Tạo repository mới trên GitHub, ví dụ `hearpaw-website`.
2. Upload toàn bộ file trong thư mục này (`index.html`, `styles.css`, `script.js`, `README.md`) lên repo.
3. Trên Render, chọn **New + → Static Site** và kết nối repo GitHub.
4. Build Command: để trống.
5. Publish Directory: `.` (dấu chấm).
6. Nhấn **Create Static Site** và chờ Render cấp URL.

## Lưu ý
Đây là frontend demo. Bản đồ, vị trí, lịch sử, hoạt động và cảnh báo đều là dữ liệu minh họa; chưa kết nối vòng cổ GPS thật, bản đồ nền thật, cơ sở dữ liệu, tài khoản người dùng hay thanh toán. Giỏ hàng và biểu mẫu không lưu qua lần tải lại trang và không gửi dữ liệu tới máy chủ.
